# Changelog

The changes of each project are listed in its own changelog:

## 2026-11-21

- **App 0.0.4 (runtime 1.1.0):** Testaments (توصيات): reminders of Jannah and Nar, advice for the Akhira and the Dunya, and athkar, as notifications on a schedule per category, with 87 built-in ones and your own. Fixed the "Log a sin" button label.

## 2026-11-20

- **App 0.0.3 (runtime 1.1.0, APK):** a "Check for updates" button in Settings, and the display name حساب.

- **App 0.0.2 (runtime 1.1.0):** weekly Akhira points (reset every Saturday, unpaid Thanb carried over) with a week history, and the display name حساب.
- **App 0.0.1 (runtime 1.1.0):** bedtime task, khushoo and mosque / home for prayers, reports, programs, debts both ways, a new Statistics tab, plain tasks, task alarms, a new icon and splash, the package `com.abdopr.apps.hisab`, and release tooling.
- **Server:** new Docker setup (`.env.docker`, prebuilt image, shared `it-pg-db`, localhost port behind a TLS proxy). No API change.

- First snapshot of the app (1.0.0, runtime 1.0.0) and the server.
