# Athan recordings

Put the athan recordings you want in this folder, then rebuild the app (they
are bundled as notification sounds, so a JavaScript reload is not enough).

- Formats: `.mp3`, `.wav` or `.ogg`.
- Names: lowercase letters, digits and `_` only, starting with a letter
  (Android rule), e.g. `makkah.mp3`, `madinah.mp3`, `fajr_makkah.mp3`.
- Use recordings you have the right to use.
- Each file appears in Prayer settings → Athan sound. A file whose name starts
  with `fajr` is a good choice for "Fajr athan" (with "الصلاة خير من النوم").
- Keep them reasonably small (under ~2 MB each); the whole file plays at
  prayer time on Android.
